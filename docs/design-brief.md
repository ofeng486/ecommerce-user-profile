# ecommerce-user-profile v2 — UI 设计简报

> **版本：** v1.0
> **风格定位：** 精致现代风 · 适度品牌化
> **技术栈：** Vue 3 + Element Plus 2.11 + Tailwind CSS 4 + ECharts 6
> **暗色主题：** 不涉及（仅亮色模式）

---

## 1. 品牌定位

| 维度 | 描述 |
|------|------|
| 产品 | 电商用户画像分析平台 |
| 目标用户 | 运营人员、数据分析师、电商管理者 |
| 品牌调性 | **专业 · 清晰 · 数据驱动 · 可信赖** |
| 设计关键词 | 干净、精致、留白、信息层级分明、微质感 |
| 差异化 | 不追求花哨，但避免"通用模板感"，每个页面都应体现数据平台的确定性 |

## 2. 配色体系

### 2.1 主色 — 蓝色 `#5D87FF`

以系统现有的 `--el-color-primary: #5D87FF` 为锚点，构建完整的语义色板。

| 语义 | 色值 | 用途 |
|------|------|------|
| `--color-primary` | `#5D87FF` | 主按钮、链接、激活态、关键高亮 |
| `--color-primary-light-3` | `#a0c0ff` | 浅色背景、hover 态 |
| `--color-primary-light-5` | `#c8dcff` | 表格行选中、tag 浅背景 |
| `--color-primary-light-7` | `#e4f0ff` | 图表浅色区域填充 |
| `--color-primary-light-9` | `#f0f7ff` | 极浅背景、卡片头部装饰 |

### 2.2 辅助色 — 克制使用

| 语义 | 色值 | 用途 |
|------|------|------|
| `--color-success` | `#13deb9` | 成功状态、高价值/KPI 正增长 |
| `--color-warning` | `#ffae1f` | 警告、流失风险标识 |
| `--color-danger` | `#ff4d4f` | 错误、危险操作、低价值标识 |
| `--color-info` | `#909399` | 辅助信息、禁用态 |

### 2.3 中性色

| 语义 | 色值 | 用途 |
|------|------|------|
| `--default-bg-color` | `#fafbfc` | 页面全局背景 |
| `--default-box-color` | `#ffffff` | 卡片/面板背景 |
| `--default-border` | `#e2e8ee` | 标准边框 |
| `--art-gray-500` | `#949eb7` | 次要文字 |
| `--art-gray-700` | `#4d5875` | 正文 |
| `--art-gray-900` | `#323251` | 标题/强调文字 |

### 2.4 图表色板（ECharts）

统一为 7 色循环，贯穿所有图表：

```
#5D87FF (蓝) → #13DEB9 (青绿) → #FFAE1F (橙) → 
#FF4D4F (红) → #A0C0FF (浅蓝) → #FFC8C8 (粉) → 
#B8EFC8 (浅绿)
```

## 3. 字体体系

### 3.1 字体栈

```css
/* 标题 — Plus Jakarta Sans 现代几何感 */
--font-heading: 'Plus Jakarta Sans', 'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif;

/* 正文 — Inter 清晰易读 */
--font-body: 'Inter', 'PingFang SC', 'Microsoft YaHei', -apple-system, sans-serif;

/* 等宽 — JetBrains Mono 开发者级 */
--font-mono: 'JetBrains Mono', 'Space Grotesk', 'Cascadia Code', monospace;

/* 数据数字 — Space Grotesk 宽体数字 */
--font-data: 'Space Grotesk', 'JetBrains Mono', monospace;
```

## 7. 组件视觉准则

### 7.1 卡片（Card）

```
┌─────────────────────────────────────┐
│ [icon] 标题               [操作区]  │  ← 头部（16px 内边距，可选 icon）
├─────────────────────────────────────┤
│                                     │
│  内容区域                            │  ← 24px 内边距
│                                     │
└─────────────────────────────────────┘
```

- 背景：白色，圆角 `--radius-md`，阴影 `--shadow-sm`
- hover：阴影升至 `--shadow-hover`，可选 `translateY(-2px)` 过渡
- 头部左侧可选 3px 品牌色竖条装饰（`::before`）

### 7.2 统计卡片（Stat Card）

```
┌──────────────────────┐
│  ● 标签名            │  ← 左侧彩色圆点/图标
│                      │
│  12,345              │  ← 大号等宽字体数值
│  ↑ 12% 较上月        │  ← 变化趋势
└──────────────────────┘
```

- 4 列等宽 Grid 布局
- 每个卡片左上角带主题色圆点（8px）或 SVG 图标
- 数值使用 `--font-mono` + 千分位格式化

### 7.3 表格（Table）

- 表头：背景 `var(--art-gray-100)`，字号 14px，字重 600
- 行高：48px（舒适）
- 行 hover：背景 `var(--el-color-primary-light-9)`
- 斑马纹：间隔行 `var(--art-gray-100)` 50% 透明度
- 操作按钮：text 类型，hover 变 primary 色

### 7.4 按钮（Button）

- 36px 统一高度
- 默认背景 `--color-primary`，hover 加深 10%
- 圆角 `--radius-sm`
- 文字按钮 hover 变 `--color-primary`

### 7.5 表单（Form）

- 标签：14px，右侧对齐
- 输入框：36px 高，圆角 `--radius-sm`
- focus：边框变 `--color-primary` + 2px 浅蓝 ring
- 错误：边框变 `--color-danger`

### 7.6 状态标签（Tag/Badge）

| 状态 | 色值 | 背景 |
|------|------|------|
| 成功/已完成 | `--color-success` | 浅绿背景 |
| 处理中/进行中 | `--color-primary` | 浅蓝背景 |
| 警告/待处理 | `--color-warning` | 浅橙背景 |
| 失败/错误 | `--color-danger` | 浅红背景 |
| 默认/未开始 | `--color-info` | 浅灰背景 |

## 10. 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Desktop | ≥1200px | 全宽布局 |
| Tablet | 768–1199px | 2 列降级，侧边栏折叠 |
| Mobile | <768px | 单列，侧边栏浮层 |

## 11. 空状态与反馈

- 所有列表/表格无数据时显示统一空状态插画 + 引导文案
- 加载状态使用 Element Plus `v-loading` + 自定义 spinner 颜色
- 错误状态使用 `el-alert` type="error" + 重试按钮
